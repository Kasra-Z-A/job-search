    Jobs from Himalayas · answers by Claude Haiku

    01 / Search

    How the job search works

    Every posting on Himalayas comes with labels for seniority, category, eligible countries, contract type and salary. The labels are stored alongside the embeddings of the job description for later retrieval. Claude Haiku extracts the labels from the user message, and filters on these labels remove the jobs that don't qualify. The remaining jobs are ranked by how similar their description is to the message.

    02 / Evaluation

    How good are the results?

    Five search systems were tested on 309 test queries. For each query, an LLM judge (Claude Haiku) graded every job in each system's top 10 as a good match, a partial match or no match, 10,967 query–job pairs in total. Each bar shows the system's nDCG@10 score. It is 1 when the best-graded jobs are ranked first and 0 when none of the top 10 jobs match.

    03 / Test method

    How the test works

    Claude Sonnet writes each test query from a real posting, with some of its requirements and the kind of work, for example mid-level HR recruiter high-volume hiring $90,000+. The judge grades a job as a good match if it meets every requirement and offers the kind of work the query asks for.

    The assistant puts at least one good match in the top 10 for 94% of queries, compared with 67% for semantic search alone. Its score stays near 0.80 as requirements are added, while the other systems score lower.

    04 / Limitations

    What the test can't show

    The main limitation is that no people are involved. An LLM wrote the test queries, so they borrow the postings' wording, and searches written by people are not tested. No person checked the grades either. Claude Sonnet regraded a sample and gave the same grade 83% of the time, but it was usually stricter, so the scores are probably slightly high.

    A second limitation is that the judge relies on Himalayas' listing details. These contain errors, and the assistant filters on the same labels, which may favour it.
