    01 / Search

    How a search works

    Every posting on Himalayas comes with labels for seniority, category, eligible countries, contract type and salary. The search uses these labels for the hard requirements in a message and the posting text for everything else. Claude Haiku turns the message into label filters, the filters remove jobs that don't qualify, and the remaining jobs are ranked by how similar their text is to the message.

    02 / Evaluation

    How good are the results?

    Five search systems ran on 309 test queries. An LLM judge (Claude Haiku) graded every job in each system's top 10, 10,967 query–job pairs, as a good match, a partial match or no match. Each bar shows nDCG@10: 1.0 means a system ranked the best-graded jobs first, 0 means its top 10 has no match.

    03 / Test method

    How the test works

    Each test query starts from a real posting. Claude Sonnet reads it and writes a request a person might type, with some of the posting's requirements and the kind of work, for example mid-level HR recruiter high-volume hiring $90,000+. Claude Haiku checks every query. Sonnet skipped 38 of 396 postings because their Himalayas labels contradict the description.

    The judge reads the query, the listing details a job seeker sees on Himalayas and the description. A good match meets every requirement the query states and offers the kind of work it asks for.

    The assistant puts at least one good match in the top 10 for 94% of queries, against 67% for semantic search alone. Its score stays near 0.80 for every query style and number of requirements, while the other systems fall as requirements are added. Labels extracted from the posting text recover about a quarter of the assistant's gain, because descriptions often leave out salary, location and contract type.

    04 / Checking the judge

    How far the grades can be trusted

    No person checked the grades. Three tests with other LLM runs show how consistent they are. Claude Sonnet regraded 300 pairs and gave the same grade 83% of the time, a weighted kappa of 0.87. Where they differ, Sonnet is usually stricter, so the scores above are probably slightly high.

    Without the listing details, the judge agrees with its own grades less (kappa 0.71): it often cannot tell whether a location or salary requirement is met. Of 100 random query–job pairs, it graded 96 as no match and none as a good match.

    The test queries are written by an LLM from real postings, so every query has at least one match and borrows the posting's wording. Searches written by people, follow-up messages and the written recommendations are not tested. Himalayas' labels contain errors, and the judge relies on them where the description is silent.
